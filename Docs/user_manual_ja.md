# StitchMaker ユーザーマニュアル

3Dモデル（靴、衣装、手袋、小物など）の表面に沿って直感的にステッチ（縫い目）のパスを配置し、Color / Normal / Height / Mask テクスチャへGPUベイクして出力するUnityエディタ拡張機能です。

対応環境: Unity 2022.3.22f1 以降 / Unity 6

## クイックスタート

細かい設定は抜きにした、最短手順でステッチテクスチャを出力するガイドです。

### Step 1: StitchMaker ウィンドウを開く
Unity上部メニューの **`dennokoworks` > `StitchMaker`** をクリックしてウィンドウを開きます。

### Step 2: 対象メッシュ（Renderer）を指定する
1. シーン内のアバターや衣装の **SkinnedMeshRenderer** または **MeshRenderer** を、**`Renderer`** フィールドにドラッグ＆ドロップします。
2. 対象メッシュに複数のマテリアルがある場合は、縫い目を配置したいスロットを **`Material`** ドロップダウンから選びます。

> [!NOTE]
> メッシュのFBXインポート設定で **`Read/Write Enabled`** が有効になっている必要があります。

### Step 3: パスを作成してシーン上で縫い目を描く
1. **`+ パスを追加`** ボタンを押します（または `編集モード` がONの状態でメッシュ上をクリックするだけでも自動でパスが作成されます）。
2. **`編集モード`** ボタンが青色（ON）になっていることを確認します。
3. **シーンビュー上でメッシュの表面を左クリック** していくと、クリックした位置に制御点が追加され、縫い目のパスが引かれます。
   - **ドラッグ**: 制御点をメッシュ表面上で移動
   - **Shift + クリック / 空いた場所をドラッグ（矩形選択）**: 複数の制御点を選択し、まとめて移動
   - **線上のクリック**: 途中に新しい制御点を挿入
   - **右クリック**: 不要な制御点を削除

### Step 4: プリセットを選ぶ
1. ウィンドウの **`ステッチ設定`** エリアにある **`プリセット`** の **`適用…`** ボタンを押します。
2. サムネイル付きの一覧が開くので、見た目を確認しながら好みのスタイル（例: `基本` の `Straight`（直線）、`Double`（2本線）、`DoubleNarrow`（間隔の狭い2本線）、`装飾` の `Cross`（クロスステッチ）、`特殊` の `Channel`（溝に埋まった縫い目）など）をクリックします。
   - サムネイルはプリセットごとに見やすい大きさへ自動で拡大・縮小しているため、プリセット同士の実際の太さ・大きさの比較には使えません。実寸はタイルにマウスを乗せると表示される長さ・幅・間隔で確認してください。
3. 必要に応じて **`糸の色`** を好みの色に変更します。

### Step 5: テクスチャを出力する
1. シーンビュー上でステッチの見た目を確認します（**`プレビュー`** がONならリアルタイムに描画されます）。
2. 必要に応じて **`解像度`**（既定値: `2048`）を選びます。
3. ウィンドウ最下部の **`テクスチャを出力`** ボタンをクリックします。
4. 出力先フォルダ（デフォルトはマテリアルと同じフォルダ内のテクスチャフォルダ）に `Color`, `Normal`, `Height`, `Mask` の各PNGファイルが生成されます。

### 対象（Target）

ステッチを投影・ベイクする対象の3Dモデルを指定します。

- **Renderer**: `SkinnedMeshRenderer` または `MeshRenderer`（`MeshFilter` を含むもの）を指定します。
- **クリア**: 割り当てられている Renderer を解除します。
- **Material**: 対象 Renderer が持っているマテリアルの一覧から、ステッチを描き込みたいサブメッシュを選択します。選択したマテリアルが参照しているテクスチャのフォルダ等から、出力先フォルダが自動提案されます。
- **メッシュを再取得**: メッシュの変形、モデルの再インポート、Read/Write設定変更などを反映させたい場合にクリックしてキャッシュを更新します。

> [!IMPORTANT]
> **メッシュの要件:**
> - FBXモデルのインスペクタで **`Read/Write Enabled`** にチェックが入っていること。
> - メッシュに **`UV0`**（テクスチャ用UV座標）が含まれていること。
> - 三角形ポリゴン（Triangle topology）で構成されていること。

### パス（Paths）とシーン操作

複数の縫い目ラインを個別管理し、シーンビュー上で直感的に配置・編集します。

#### ドキュメント管理
- **新規**: 現在のパス設定をクリアし、空の新規ドキュメントを作成します。
- **読込**: 保存済みのパスアセット（`.asset`）を読み込みます。
- **保存**: 現在作成したすべてのパスと出力設定をプロジェクト内に `.asset` ファイルとして保存します。別の衣装への流用やバックアップに便利です。

#### パスリスト
- **パスの選択**: リスト内のパス名をクリックすると、そのパスが編集対象になります。
- **目のアイコン（表示 / 非表示）**: パスごとの描画と出力を切り替えます。非表示のパスはプレビューおよびベイク出力から除外されます。
- **× ボタン**: 選択したパスを削除します。
- **右クリックメニュー**: パスの行を右クリックすると、次の操作ができます。
  - **複製**: 形状・ステッチ設定・ミラー設定ごとパスを複製し、元のパスの直後に追加します。
  - **ステッチ設定をコピー / 貼り付け**: ステッチ設定（マスク・スケール・長さ・幅・糸の色・溝など）を別のパスへ写します。形状とミラー設定は変わりません。コピーした設定は Unity を終了するかスクリプトが再コンパイルされるまで保持されます。
- **+ パスを追加**: 新しいパスを末尾に追加します。パスを選択中の場合は、そのパスのステッチ設定（マスク・スケール・長さ・幅・糸の色など）を引き継ぐので、同じステッチを複数箇所に入れるときに便利です。形状（制御点・閉じる・ベジェハンドル）とミラー設定は引き継ぎません。

#### パス編集コントロール
- **編集モード**: シーンビューでのパス編集機能のON/OFFを切り替えます。
  - **ON**: シーンビュー上のオブジェクト選択を抑止し、メッシュ上をクリック・ドラッグしてパスを編集できます。シーンビュー右下に緑の操作ガイドが表示されます。
  - **OFF**: 通常のUnityシーン操作（他のオブジェクトの選択やトランスフォームギズモ操作）に戻ります。
- **閉じる（Closed）**: チェックを入れると、パスの始点と終点が結ばれ、襟元や袖口、裾などの一周するループ状の縫い目になります。
- **ベジェハンドル（Bezier Handles）**:
  - **OFF（自動補間）**: 制御点を打つだけで自動的に滑らかな曲線（Catmull-Romベース）が計算されます。通常はこちらで直感的に作業できます。
  - **ON（手動ベジェ）**: 各制御点からピンク色のベジェハンドルが表示され、ハンドルの先端をドラッグすることで曲率やカーブの向きを微調整できます。

#### シーンビューでのマウス操作

| 操作 | 動作 |
| :--- | :--- |
| **メッシュ上を左クリック** | 新しい制御点を追加（既存パスの末尾、または選択ノードの次に追加） |
| **パスの線上を左クリック** | 線上のクリックした位置に新しい制御点を中間挿入 |
| **制御点をドラッグ** | 制御点をメッシュ表面に沿って移動（複数選択中の制御点を掴むと、選択した制御点をまとめて移動） |
| **Shift + 制御点を左クリック** | 制御点を選択に追加（選択済みなら解除） |
| **空いた場所を左ドラッグ** | 矩形選択（Shift を押しながらで今の選択に追加）。メッシュ上の空いた場所からドラッグしても制御点は追加されません |
| **メッシュの外を左クリック** | 選択を解除 |
| **ハンドルをドラッグ** | （ベジェハンドルON時）カーブの方向と曲率を調整 |
| **制御点を右クリック** | クリックした制御点を削除 |
| **Alt + 左ドラッグ / 右ドラッグ** | Unity標準のシーンカメラ回転・ズーム（パス編集を邪魔せず通常通り動作します） |

### ステッチ設定（Stitch Settings）

リストで選択しているパス固有の縫い目パラメーターを設定します。

#### プリセット
- **適用…**: 同梱プリセットとユーザー自作プリセットをサムネイル付きの一覧で表示し、クリックしたものを現在のパスに適用します。同梱プリセットはカテゴリごと、自作プリセットは「保存済み」の下に並びます。
- **削除…**: 保存済みの自作プリセットを削除します。
- **フォルダ**: ユーザー自作プリセットが保存されているフォルダ（OSのAppData領域）をエクスプローラー等で開きます。プリセットのバックアップや共有に利用できます。
- **プリセット名 & 保存**: 入力した名前で現在のステッチ設定（マスク画像を含む）をプリセットとして保存します。

#### パラメーター一覧

| パラメーター | 単位 / 範囲 | 説明 |
| :--- | :--- | :--- |
| **名前** | 文字列 | パスの名称です。 |
| **マスク** | Texture2D | ステッチ1粒の形状を定義する白黒テクスチャです。白が高さ・縫い目、黒が背景となります。※未設定のパスは描画されません。 |
| **スケール** | 0.25 〜 4 倍 | 長さ・幅・間隔・ゆらぎ（位置）にまとめて掛ける倍率です。縫い目のバランスを保ったまま、全体の大きさだけを変えられます。下の各項目に表示される値は倍率を掛ける前の値です。プリセットを適用すると 1.0 に戻ります（スケール付きで保存した自作プリセットは、その倍率になります）。 |
| **長さ** | 0.5 〜 20 mm | ステッチ1粒の進行方向の長さです。 |
| **幅** | 0.1 〜 10 mm | ステッチ1粒の幅です。 |
| **間隔** | 0.5 〜 30 mm | パスに沿って縫い目を並べるピッチ（中心間距離）です。長さに近い値にすると連続した縫い目になり、広げると点線状になります。 |
| **角度** | -180 〜 180° | パスの接線方向からの回転オフセットです。斜めステッチやクロスステッチの角度調整に使用します。 |
| **糸の色** | Color (RGB) | 糸のカラーです。Colorテクスチャ出力時に反映されます。 |
| **高さ** | 0 〜 1 | Heightテクスチャにおけるステッチの高さスケールです。 |
| **凹凸の強さ** | 0 〜 2 | Normalマップにおけるステッチの法線凸凹の強さです。 |
| **溝の幅** | 0 〜 10 mm | パスに沿って布地を凹ませる溝の幅です。0 で溝なしです。靴のコバ周りのように、溝の中に縫い目が沈んだ表現に使います（プリセット `Channel`）。スケールも掛かります。 |
| **溝の深さ** | 0 〜 2 | 溝の壁の傾きです。溝は Normal マップにだけ現れ、Color と Height には影響しません（Height は布地の高さが 0 のため、それより低い溝を持てません）。 |
| **ゆらぎ・位置** | 0 〜 2 mm | ステッチの位置にランダムな揺らぎを加えます。手縫い感や自然な粗さを表現したい場合に有効です。 |
| **ゆらぎ・角度** | 0 〜 30° | ステッチの角度にランダムな傾きを加えます。 |
| **Seed** | 整数 | ゆらぎの乱数シード値です。数値を変更すると揺らぎのパターンが変わります。 |

### ミラー機能（Mirror）

衣装や靴など、左右対称のモデルで反対側にも同じステッチを配置したい場合に使用します。
3D空間上で鏡映反転を行うため、左右でUVアイランドが独立している一般的なアバター・衣装モデルでも綺麗に反対側へベイクされます。

| パラメーター | 説明 |
| :--- | :--- |
| **ミラー軸** | `None`, `X`, `Y`, `Z` から対称軸を選択します（通常の人型モデルではメッシュローカルの左右対称となる **`X`** を選択します）。選択するとシーンビュー上に半透明でミラープレビューが表示されます。 |
| **吸着半径 (mm)** | 反対側のメッシュ表面へ制御点を自動吸着させる探索距離（既定値: `30 mm`）です。スカルプトの微妙な左右非対称や服のシワ、ドレープの違いがあっても、反対側の表面にぴったり追従します。 |
| **独立パスとして実体化** | ミラー側の縫い目を、手動編集可能な**別の独立したパス**として複製・実体化し、元パスのミラーを `None` に戻します。左右で一部だけデザインを変えたい場合や、個別にノードを微調整したい場合に便利です。 |

> [!WARNING]
> **UV配置の注意点:**  
> 左右で同一のUV領域を重ねて配置（UVアイランドを共有）しているローポリゴンモデル等の場合、ミラーを有効にすると同じ場所に二重でベイクされてしまいます。**UVアイランドを重ねて共有しているメッシュでは、ミラーを OFF にしてください。**

### プレビュー・出力（Preview / Export）

#### リアルタイムプレビュー
- **プレビュー Toggle**: シーンビュー上でのステッチプレビュー描画のON/OFFです。
- **表示モード**:
  - **Combined**: 陰影・カラー・法線を統合した完成状態のプレビューです。
  - **Normal**: 法線マップ（ノーマル）の凹凸状態を確認できます。
  - **Height**: ハイト（高さ情報）の白黒グラデーションを確認できます。

#### 出力設定
- **解像度**: 出力するテクスチャの解像度を `512`, `1024`, `2048`, `4096` から選択します（衣装の元テクスチャの解像度に合わせることを推奨します）。
- **パディング (px)**: UVアイランドの境界線から外側へテクスチャを拡張するピクセル数（既定値: `4 px`）です。ミップマップ生成時の黒ずみや継ぎ目の滲みを防ぎます。
- **アンチエイリアス**: 出力時に縦横 2 倍 / 4 倍の解像度で描いてから縮小し、ステッチの輪郭や曲線のギザギザ（ジャギー）を抑えます（既定値: `2x`）。
  - **OFF**: 解像度そのままで描画します。最も高速です。
  - **2x**: 通常はこちらを推奨します。
  - **4x**: さらに滑らかになりますが、出力に時間と VRAM を多く使います。
  - 内部の作業解像度は最大 `8192 px` です。解像度 `4096` で `4x` を選んだ場合などは上限を超えるため、自動的に `2x` で出力されます（設定欄の下に注記が表示されます）。
  - アンチエイリアスはテクスチャ出力時にのみ掛かります。編集中の動作を軽く保つため、シーンビューのプレビューには反映されません。
- **出力チェックボックス**:
  - **Color**: 糸の色・形状テクスチャ（ステッチ以外は透明なRGBA PNG）。
  - **Normal**: 法線マップテクスチャ（UnityのTexture Typeが自動で `Normal map` に設定されます）。
  - **Height**: 高さ情報テクスチャ（リニアグレースケール）。
  - **Mask**: 白黒マスクテクスチャ（ステッチ部分が白、背景が黒）。
- **上書き保存**:
  - **ON**: 既に出力先に同名ファイルが存在する場合、上書きします。
  - **OFF**: 同名ファイルが存在する場合、末尾に `_1`, `_2` などの連番を付与して別名保存します。
- **ステッチ以外を透過**:
  - **ON**: Color だけでなく、Normal や Height も「ステッチ以外の背景部分を完全透過（アルファ 0）」にして出力します。ペイントソフト等で既存のテクスチャの上にレイヤーとして重ねてブレンドしたい場合に最適です。溝を設定したパスでは、糸の無い溝の部分も Normal に残ります。
    - ※ Unity の Texture Type「Normal map」ではアルファが透過として扱われないため、透過出力時の Normal は Texture Type「Default」（sRGB OFF、Alpha Is Transparency ON）で保存されます。Unity 上でシェーダーの法線マップとして直接使う場合は、インポート設定で Texture Type を「Normal map」に変更してください。
  - **OFF**: Normal はフラットな法線色（#8080FF）、Height は黒（#000000）で背景を塗りつぶして出力します。
- **出力先**: テクスチャを保存するプロジェクト内のフォルダ（`Assets/...`）を指定します。`...` ボタンからフォルダ選択ダイアログを開くこともできます。
- **テクスチャを出力**: ベイクを実行し、PNGファイルとして保存します。出力後、UnityのProjectウィンドウで該当フォルダがハイライト表示されます。

#### 出力ファイル名規則
指定したフォルダ内に、以下の命名規則でファイルが出力されます：
- `{Renderer名}_Stitch_Color.png`
- `{Renderer名}_Stitch_Normal.png`
- `{Renderer名}_Stitch_Height.png`
- `{Renderer名}_Stitch_Mask.png`

## トラブルシューティング / よくある質問

### Q. 「メッシュの頂点を読み取れません（Read/Write を有効にしてください）」と表示される
**A.** 対象モデルのインポート設定で Read/Write が無効になっています。
1. Projectウィンドウで対象モデルの元ファイル（FBX等）を選択します。
2. Inspectorの `Model` タブを開きます。
3. **`Read/Write Enabled`**（または `Read/Write`）にチェックを入れて `Apply` を押してください。
4. StitchMaker ウィンドウの **`メッシュを再取得`** ボタンを押します。

### Q. 「メッシュに UV0 がありません」と表示される
**A.** 3Dモデルにテクスチャマッピング用のUV座標（UV0）が含まれていません。Blender等のDCCツールでUV展開を行ってください。

### Q. シーンビューでクリックしても制御点が追加されない
**A.** 以下の点を確認してください：
1. **`編集モード`** ボタンが青色（ON）になっているか確認してください。
2. 対象メッシュの表面をクリックしているか確認してください（メッシュの外側をクリックしてもノードは配置されません）。
3. シーンビューが2Dモードになっていないか、メッシュの裏面からクリックしていないか確認してください。

### Q. シーンビューでオブジェクトを選択したいのにステッチが打たれてしまう
**A.** パスの編集が完了したら、ウィンドウの **`編集モード`** ボタンを押してOFFにしてください。通常のUnityオブジェクト選択に戻ります。

### Q. 出力したステッチテクスチャはどう使えばいい？
**A.** 主に以下の2つの方法があります：
1. **ペイントソフトで合成（おすすめ）**:
   Photoshop、Clip Studio Paint、Affinity Photo等で、元の衣装テクスチャの上に `_Stitch_Color.png` を通常レイヤーとして重ね、`_Stitch_Normal.png` は法線合成（またはオーバーレイ・専用合成モード）で重ねて1枚のテクスチャとして結合します。
   ※「ステッチ以外を透過」をONにして出力すると重ねやすくなります。
2. **シェーダーの追加スロットに指定**:
   lilToon や Poiyomi などの高機能シェーダーを使用している場合、「メインカラー 2nd」や「詳細ノーマルマップ（Detail Normal）」のスロットに直接 StitchMaker の出力テクスチャを指定してブレンドすることも可能です。
