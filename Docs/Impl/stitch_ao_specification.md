# 糸の穴・沈み込み（AO）仕様書

## 1. 背景と目的

レザーのステッチでは、糸を通す穴が凹んで影になり、糸に引っ張られた周りの革が少し沈み込む。今の StitchMaker は糸の盛り上がり（マスク）と溝しか描けないので、ステッチが表面に「乗っている」ように見えてしまう。

本仕様では次の 2 つを追加する。

| 表現 | 内容 |
| :--- | :--- |
| **穴** | 糸が革に入る位置の凹み。糸の先端の外側に影が見える |
| **沈み込み** | 糸の形に沿って周りの革が沈む。糸から離れるほど浅くなる |

どちらも **Normal** に凹みとして出し、さらに影だけを **AO 画像** として別に書き出す。AO はベースマップへの焼き込みや、マテリアルの AO スロットに使う。既存の **溝** も AO に出す。

### 1.1 決定事項の要約

| 項目 | 決定 |
| :--- | :--- |
| 穴の位置 | **マスクから自動で決める**（糸の端と、折り返しの V 字の頂点）。穴マスク画像は使わない（位置の調整が難しいため。§3.1） |
| 穴の調整 | **大きさ**（糸の太さに対する倍率）と **深さ** だけ |
| 沈み込みの形 | 糸の形に沿う（マスクをぼかした形）。幅は mm で指定する |
| パラメータの単位 | パスごと（`StitchSettings`。プリセットにも保存する） |
| パラメータ | 穴と沈み込みそれぞれの ON/OFF と、穴の大きさ・穴の深さ・沈み込みの幅・沈み込みの深さ。「深さ」が AO の濃さと Normal の傾きの両方を決める。溝の AO は「溝の深さ」に連動する |
| 既定の状態 | 穴・沈み込みとも **OFF**。布のステッチなどでは不要なため。既存の `.asset` と古いプリセットは OFF として読み込まれ、出力が変わらない |
| Normal | 穴と沈み込みの両方を出す |
| Height | 変更しない（0 = 布地のまま） |
| AO 出力 | グレー 1 枚（`_Stitch_AO.png`、白 = 影なし）。透過出力時は黒＋アルファ |
| AO と糸 | 糸の部分は AO を掛けない（白） |
| UI | ステッチ設定の下に独立した折りたたみセクション「穴・沈み込み (AO)」を置く |
| プレビュー | 表示モード「AO」を追加し、Combined の布地部分にも AO の影を重ねる |

## 2. データ

### 2.1 StitchSettings

| フィールド | 単位 / 範囲 | 既定値 | 内容 |
| :--- | :--- | :--- | :--- |
| `hole` | bool | false | 穴を描く |
| `holeSize` | 倍率、0.2–4 | 1 | 先端での糸の太さに対する穴の大きさ（§3.1） |
| `holeDepth` | 0–1 | 0.5 | 穴の深さ。AO の濃さ（穴の中心での `1 − AO`）と、Normal の傾きを決める |
| `sink` | bool | false | 沈み込みを描く |
| `sinkWidth` | m（UI は mm、0–5） | 0.001 | 糸の縁から沈み込みが広がる距離（この距離でなだらかに 0 になる）。`scale` を掛ける（`ScaledSinkWidth`） |
| `sinkDepth` | 0–1 | 0.3 | 沈み込みの深さ。糸の縁での AO の濃さと、Normal の傾きを決める |

- `HasHole => hole && holeSize > 0 && holeDepth > 0`、`HasSink => sink && sinkWidth > 0 && sinkDepth > 0`。
- ON/OFF は `bool` で持ち、大きさ・深さには 0 でない既定値を入れておく。ON にした直後から効果が見えるようにするため。
- 既存の `.asset` を開いたとき、無いフィールドは既定値（OFF）になる。古いプリセット（JSON に項目が無い）も `OverwriteFromPreset` で既定値に戻してから読むので OFF になる。どちらも出力は今までと変わらない。
- Normal の傾きには、さらに既存の `normalStrength` を掛ける（糸と同じ強さの基準にする）。
- 溝の AO は `grooveDepth` から求める（新しい項目は増やさない。§3.4）。
- 穴の位置はマスクから求めるので、`StitchPath` やプリセットに新しいテクスチャは持たない。プリセットの保存形式（`{name}.json` + `{name}.png`）も変わらない。

### 2.2 ExportSettings

| フィールド | 既定値 | 内容 |
| :--- | :--- | :--- |
| `ao` | false | `_Stitch_AO.png` を出力する。既存の `.asset` で出力したときに、今まで無かったファイルが増えないよう OFF にする |

## 3. 描画

### 3.1 穴の位置（`HoleDetector`）

糸が革に入る点は、マスクの上では「糸の輪郭が外側へ大きく曲がって終わる所」に現れる。丸い糸の端は輪郭が 180° 回り込み、折り返しの V 字の頂点は 180° − 腕の開きだけ曲がる。一方、糸の脇は真っ直ぐかうねる程度で、糸同士が交わる所は内側へ凹む。これを使って先端を探す。

1. マスクを GPU で描いて読み戻す（インポート設定の Read/Write に依存しない）。最大辺 512px を超えるマスクは縮小する。
2. 左右の端に糸がある（タイル可能な）マスクは、3 つ横に並べた画像で調べ、真ん中の分の先端だけを使う（継ぎ目の V 字も 1 つの先端として見つかる）。外周は 0 で 1px 囲み、輪郭を必ず閉じる。
3. 被覆率のしきい値（マスク値 0.05。シェーダーの被覆率 `saturate(m × 20)` と揃える）の等値線を、マーチングスクエアで閉じた折れ線として取り出す。
4. 背景までの距離（2 乗距離変換）の尾根（局所最大）の中央値を、糸の典型的な半径 `r` とする。
5. 各折れ線を 0.5px 間隔に取り直し、画素の段差を消すため 1px のガウスで平滑化する。糸が進行方向の左になる向きに揃える。
6. 各点で、前後合わせて「半径 `r` の半円の弧」の長さの区間で接線の向きの変化を求め、**外側へ 100° 以上** 曲がる所を先端の候補とする。区間が重なる候補は、曲がりの大きい方だけを残す。
7. 先端の位置は、区間の両端を結ぶ弦の外向きの法線方向に最も突き出た点（区間をその点に合わせて数回やり直す）。向きはその法線。
8. 先端での糸の半径は、先端から内側へ `1.5r` 進む間の背景までの距離の最大。
9. 画像の上下（タイルしないマスクは左右も）の端に掛かる先端は、画像の端で切れた糸なので除く。

同梱マスクでの結果（Python の試作と C# の両方で確認）:

| マスク | 見つかる穴 |
| :--- | :--- |
| Straight / Double / Triple / DoubleNarrow / TripleNarrow / Thick / Twisted / FlatWaxed / Rough / Whip / Cross / DoubleCross / Baseball / Herringbone | 各ストロークの両端 |
| Zigzag | 上下の折り返しの頂点（左右の端の頂点は 1 つの穴として、反対側へ回り込ませて描く） |
| Blanket | 縦の糸の下端（上端は横の糸に繋がるので穴なし） |
| Chain | 輪の尖った端（丸い端は曲がりが緩いので穴なし） |
| Overlock | なし（針が針糸の上に落ちるため、先端が輪郭に出ない） |

結果はマスク（インスタンスと `updateCount`）ごとにキャッシュする。

### 3.2 穴のテクスチャ

- 各先端に、半径 `1.0 × 糸の半径 × holeSize`（糸と同じ太さ）の円を、先端から外側へ `0.25 × 糸の半径 × holeSize` の所を中心にして描く。深さの形は、中心から半径の 45% までが平らな底（1）で、そこから縁へ `smoothstep` でなめらかに 0 になる。重なりは深い方。
- 糸の先端は穴の内側の縁に少し掛かるだけで、穴の大部分（先端から外へ `1.25 × 糸の半径 × holeSize`）が影として見える。`holeSize` は先端を中心に穴を拡大・縮小する。（当初は半径 1.35 倍の円を先端の内側 0.65 倍の所に置き、外側の三日月形だけを見せていたが、最も深い中心が糸に隠れて影がほとんど見えなかったため変えた。）
- 解像度は検出と同じ（穴の半径が 8px 未満なら最大 4 倍に拡大）。RHalf の Texture2D に描く。
- マスクの外へはみ出す穴は、はみ出す分の余白を付けて描く。左右に繋がるマスクは、はみ出した分を反対側へ回り込ませて描く（横の余白なし）。シェーダーには `_HoleRect`（マスク座標 → テクスチャ座標 = `m × xy + zw`）を渡す。
- `ReliefRenderer` が（マスク、`updateCount`、`holeSize`）ごとにキャッシュし、その回の描画で使われなかったものは解放する。

### 3.3 沈み込みのフィールド

沈み込みは「糸の縁からの実寸の距離」で深さを決める。UV 密度に左右されないよう、ステッチ座標で求める。

1. パスごとに、マスクの周囲へ `sinkWidth` 分の余白を付けたキャンバス（ステッチ座標で `(length + 2·sinkWidth) × (width + 2·sinkWidth)`）を用意する。解像度は最大辺 512px で、マスクの画素より細かくはしない。
2. キャンバスの各画素でマスク（`MaskReadback` で読み戻したもの）を引き、マスク値 > 0.05（被覆率が 1 になる値）を糸の画素とする。左右の端に糸がある（タイル可能な）マスクは、余白に隣の目の糸を繰り返して置き、継ぎ目で途切れないようにする。
3. 糸までの実寸の距離 `d` を距離変換（`DistanceField`。Felzenszwalb の 2 乗距離変換で、縦横の画素の大きさを別々に扱う）で求める。
4. `sinkField = 0.5 + 0.5·cos(π · min(d / sinkWidth, 1))`。糸の縁で 1、`sinkWidth` 離れると 0 で、両端で傾きが 0 になるなだらかな形。キャンバスの端（糸から `sinkWidth` 以上離れる）では必ず 0 になるので、余白の境目に段差が出ない。
5. 糸の太さや `sinkWidth` に関係なく、糸の縁では常に最大の深さになる（当初はマスクの被覆率をガウスでぼかしていたが、幅を広げると糸に対してぼかしが大きくなり、全体が浅くなって広がって見えなかったため変えた）。
6. `ReliefRenderer` が（マスク、length、width、sinkWidth）ごとに RHalf の Texture2D でキャッシュし、その回の描画で使われなかったものは解放する。
7. シェーダーには `_SinkRect`（マスク座標 → キャンバス座標）を渡す。

### 3.4 穴・沈み込みのデカール

- 穴と沈み込みは、ステッチ 1 目ごとに四角形を余白だけ広げたデカールで描く（既存の `DecalMeshBuilder.Build(snapshot, length, width, ...)` に余白付きの長さ・幅を渡す）。余白は `sinkWidth`（沈み込みが ON のとき）と穴のはみ出しの大きい方で、縦横共通。
- 深さ（布地からの凹み）は `sink = sinkDepth · sinkField`、`hole = holeDepth · 穴のテクスチャ` とし、`depth = max(sink, hole)` とする。
- **AO**: `1 − depth`（Pass 9）。
- **Normal**（Pass 8）: 深い方の凹みの勾配から、糸と同じ式で求める（凹みなので向きは糸と逆）。凹みの高さの単位は糸と同じ `normalStrength × width`（深さ 1 = 糸の盛り上がりと同じ深さ）。勾配はそれぞれのテクスチャ座標あたりなので、テクスチャ 1 枚分の実寸で割る。凹みの無い画素は書かない。
- **Color / Height**: 溝と同じく、糸色・被覆率 0・高さ 0 を書く。
- 穴の検出（マスクの読み戻し）と沈み込みフィールドの生成は RenderTarget を変えるので、そのパスの描画先を設定する前に済ませる（`ReliefRenderer.Prepare`）。

### 3.5 溝の AO

溝（Pass 4）にも AO を出す。底（中央 40%）を最も暗くし、壁で布地の明るさへ戻す。

```
y   = |2t − 1|
u   = saturate((y − 0.4) / 0.6)
AO  = 1 − 0.5 · grooveDepth · (1 − smoothstep(u))
```

（係数 0.5 はシェーダーの `GrooveOcclusion`。）

### 3.6 重なりの扱い

**AO**
- 専用のターゲット（R8、クリア値 1）に、穴・沈み込み・溝の AO を **最小値ブレンド**（`BlendOp Min`、深度テストなし）で描く。暗い方が勝つので、隣の目と重なっても描く順番に関係なく同じ結果になる。
- 全パスを描いた後、`AO = lerp(AO, 1, 被覆率)` で **糸の部分を白に戻す**。糸の先端に覆われた穴の部分も白になる。

**Normal**
- 穴・沈み込み・溝は、深度を「マスク値 0 より手前、糸（マスク値 > 0）より奥」の帯（`0.0005 + 0.001 × saturate(傾き)`）に収め、その中で **傾きが大きい方が勝つ** ようにする。
  - 糸の余白（マスク値 0）では上書きされず、糸は常に上に乗る。
- 隣の目の沈み込みと重なる所では、2 つの凹みを足し合わせず、傾きの大きい方の法線を使う（v1 の制約。§6）。

### 3.7 パディングとアンチエイリアス

- AO ターゲットにも、他のマップと同じ Dilate を `padding` 回掛ける。
- SSAA の縮小は算術平均（Height と同じ Pass 7 を使う）。

## 5. 出力

| ファイル | 内容 | インポート設定 |
| :--- | :--- | :--- |
| `{Renderer名}_Stitch_AO.png` | グレースケール（255 = 影なし、0 = 最も暗い） | sRGB OFF |
| 透過出力（`transparent`）時 | RGB = 黒、A = `1 − AO` | sRGB OFF、Alpha Is Transparency ON |

- 透過出力の AO は、画像編集ソフトでベースマップの上に通常レイヤーとして重ねるだけで焼き込める。
- 不透明の AO は、ベースマップに乗算で重ねるか、マテリアルの AO（Occlusion）スロットに割り当てる。
- 連番・上書き保存・インポート設定の扱いは他のマップと同じ。

## 6. 既知の制約

- 隣り合う目の沈み込みが重なる所では、Normal の凹みは足し合わされず、傾きの大きい方が使われる。間隔が狭く沈み込みの幅が広いと、目と目の間の凹みが浅く見えることがある。
- AO は糸と革の形から求めた近似で、周囲のメッシュ形状（隣のパーツの陰など）は含まない。
- 穴の位置はマスクの輪郭から推定する。針が別の糸の上に落ちるマスク（同梱では Overlock）は先端が輪郭に出ないので穴が出ない。また、緩く曲がって終わる糸（先端が細く尖らず、半円より緩い）や、糸の脇の大きなこぶは、意図と違う判定になることがある。
- 糸自身の陰（糸が穴に潜り込む先端の暗さなど）は AO に含めない。

## 8. 決定済みの補足

| 項目 | 決定 |
